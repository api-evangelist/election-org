Election.org Public Data API provides free, anonymous access to a wide range of civic election data, including linked civic JSON datasets and federal CSV files. Users can retrieve information on candidates, results, campaign finance, and more, supporting public insight and research without requiring authentication or payment.

**Areas:** Elections · Public Records · Data API · Campaign Finance · Government · Political Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Election.org Public Data API: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
